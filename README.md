# 🕌 Islamic Tours - Мобильное приложение турагентства

Мобильное приложение для организации мусульманских религиозных туров (Умра, Хадж, Зиярат).

## 📱 Возможности

- ✅ Просмотр ближайших туров
- ✅ Полный каталог туров с фильтрацией
- ✅ Детальная информация о каждом туре
- ✅ База знаний о паломничестве
- ✅ Виртуальный кошелёк с автопополнением
- ✅ История транзакций

## 🛠 Технологии

- React Native (Expo)
- Lucide React Native (иконки)
- Context API для управления состоянием
- JSON для хранения данных

## 🚀 Установка и запуск

### Предварительные требования

- Node.js (v14 или выше)
- npm или yarn
- Expo CLI

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone <your-repo-url>
cd islamic-tours
```

2. **Установите зависимости**
```bash
npm install
```

3. **Запустите проект**
```bash
npx expo start
```

4. **Запуск на устройстве**
   - Для iOS: нажмите `i`
   - Для Android: нажмите `a`
   - Для Web: нажмите `w`
   - Или отсканируйте QR-код в приложении Expo Go

## 🎨 Дизайн

Приложение использует спокойную цветовую палитру с исламским зелёным (#047857) в качестве основного цвета, создавая атмосферу доверия и духовности.

## 📊 Данные

Все данные хранятся локально в JSON файлах:
- **tours.json** - информация о турах
- **knowledge.json** - статьи базы знаний
- **wallet.json** - данные виртуального кошелька

## 🔧 Настройка

### Изменение цветовой схемы

Отредактируйте файл `src/styles/colors.js`

### Добавление новых туров

Добавьте данные в `data/tours.json`

### Добавление статей

Добавьте статьи в `data/knowledge.json`
